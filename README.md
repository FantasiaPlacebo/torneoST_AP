# 🍭 Dulce Golosía - Página E-commerce

> **Proyecto ganador del Torneo de Programación Web - Instituto Profesional Santo Tomás 2025**

## 🏆 Contexto del Proyecto

**Dulce Golosía** es una página web para una tienda de golosinas ficticia, desarrollada como parte del **Torneo de Programación Web 2025** del Instituto Profesional Santo Tomás.

### 📋 Desafío
- **Duración**: 2 horas
- **Equipo**: 2 personas
- **Caso**: Desconocido al inicio (revelado durante la competencia)
- **Resultado**: 🥇 **Ganador del torneo**

El proyecto fue destacado por su diseño visual atractivo, funcionalidad clara y originalidad en la presentación.

---

## ✨ Características

- ✅ Diseño responsivo (HTML5/CSS3)
- ✅ Interfaz visual atractiva y profesional
- ✅ Navegación intuitiva
- ✅ Estética optimizada para e-commerce
- ✅ Estructurado bajo presión en tiempo limitado
