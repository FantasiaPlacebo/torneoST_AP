# 🍭 Dulce Golosía

Página web de tienda de golosinas ganadora del Torneo de Programación Web 2025.

## 🏆 Detalles

- **Competencia**: Torneo de Programación Web 2025 - Instituto Profesional Santo Tomás
- **Duración**: 2 horas
- **Equipo**: 2 personas
- **Resultado**: 🥇 Ganador

## 🛠️ Tecnologías Utilizadas

| Tecnología | Descripción |
|-----------|------------|
| **HTML5** | Estructura semántica y accesibilidad |
| **CSS3** | Estilos, diseño responsivo, animaciones |

## 🚀 Cómo Abrir

1. Descarga el repositorio:

git clone https://github.com/FantasiaPlacebo/tornoeST_AP.git

2. Abre index.html en tu navegador

O usa un servidor local:

python -m http.server 8000

Luego ve a http://localhost:8000
